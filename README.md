# Cybersecurity Threat Analysis on Secure Pay Technologies


# CYBERSECURITY THREAT ANALYSIS
**SQL Data Analysis Internship Project – Summary Report**

### 1. Project Overview
This project focuses on analysing cybersecurity incidents recorded by SecurePay Technologies, a fictional financial technology company. Using SQL, the analysis investigates suspicious activities, including brute-force attacks, phishing, malware, DDoS, SQL injection, ransomware and unauthorised access.

### 2. Database Structure
The analysis involves five relational database tables:

- **attack_logs:** Records attack dates, types, severity, source IPs and incident status.
- **systems:** Contains information about company systems, departments and security levels.
- **users:** Stores employee usernames, departments and job roles.
- **ip_addresses:** Provides source IP information, countries and threat categories.
- **incident_responses:** Contains response actions, response times and resolution statuses.

### 3. Analytical Approach
SQL queries are used to explore the database, aggregate incident records and identify cybersecurity trends. The investigation focuses on:

- Total number and distribution of cyberattacks.
- Most frequently occurring attack types.
- Percentage of High and Critical severity incidents.
- Blocked versus unblocked attacks.
- Attack patterns across days and hours.
- Departments and systems experiencing the highest attack volumes.
- Countries associated with the highest number of attacking IP addresses.

### 4. Project Deliverables
The expected deliverables include SQL scripts, query results and explanations of findings. Calculations, rankings and percentages are used to support evidence-based recommendations. Visualisations or dashboards may also be incorporated to communicate the findings effectively.

### 5. Conclusion
The project provides practical experience in relational database analysis, SQL querying, data aggregation and cybersecurity threat investigation. It demonstrates how structured data analysis can help organisations understand attack patterns, identify potential vulnerabilities and make informed security decisions.
